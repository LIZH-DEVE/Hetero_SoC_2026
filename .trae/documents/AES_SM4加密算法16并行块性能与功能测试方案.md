## 基于 `tb_dma_subsystem_crypto_encdec.sv` 的全面测试方案

### 一、测试文件修改计划

基于最新测试台 `tb_dma_subsystem_crypto_encdec.sv`，添加以下功能：

#### 1.1 新增测试任务

| 任务名称 | 功能描述 |
|----------|----------|
| `test_16_parallel_blocks` | 16并行块加密解密验证 |
| `test_throughput_aes` | AES吞吐量测试（1KB/10KB/100KB/1MB） |
| `test_throughput_sm4` | SM4吞吐量测试（1KB/10KB/100KB/1MB） |
| `test_backpressure` | 背压模拟测试 |
| `test_key_switch` | 密钥动态切换测试 |
| `test_stability` | 稳定性测试（10000次操作） |

#### 1.2 性能统计功能

- 吞吐量计算（MB/s）
- 延迟统计（周期数）
- 成功率统计
- 资源利用率监控

---

### 二、测试内容详情

#### 2.1 功能完整性测试

```
测试项：
├── AES-128 ECB模式 加密/解密
├── SM4 ECB模式 加密/解密  
├── 16并行块同时传输
├── 数据完整性校验（CRC32）
└── 往返测试（加密→解密→比对原始数据）
```

#### 2.2 吞吐量性能测试

```
数据块大小：1KB、10KB、100KB、1MB
重复次数：每个场景3次取平均
统计指标：
├── 吞吐量（MB/s）
├── 处理延迟（时钟周期）
├── 16实例并行效率
└── FIFO利用率
```

#### 2.3 异常场景测试

```
├── 非对齐数据块处理
├── 背压（FIFO满）模拟
├── 密钥动态切换
├── 连续操作稳定性
└── 错误恢复测试
```
