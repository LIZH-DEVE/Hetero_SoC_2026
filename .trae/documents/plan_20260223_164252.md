## 修复测试台文件计划

### 问题分析
当前 `tb_full_system_test.sv` 存在以下问题：
1. 数组 `input_data [0:15]` 大小不足（需要64个元素）
2. 缺少实际加密/解密结果的数据比对
3. 预测值只显示文本，未计算实际预期值

### 修复方案

#### 1. 修正数组大小
```systemverilog
// 改为64个元素以支持16实例×4字/块的并行数据
reg [31:0] input_data  [0:63];
reg [31:0] output_data [0:63];
```

#### 2. 添加预测结果计算
- **加密预测**: 使用简单的可逆变换作为"预期加密结果"参考模型
- **解密预测**: 与原始输入比对验证往返一致性

#### 3. 添加实际结果捕获和比对
- 在接收端捕获实际输出数据
- 与预测值进行比对并报告结果

#### 4. 改进测试输出
```
[预测加密结果] 0xXXXXXXXX ...
[实际加密结果] 0xXXXXXXXX ...
[比对结果] PASS/FAIL
```

### 预期成果
- 修正数组大小错误
- 添加预测值与实际值的比对功能
- 保持16实例并行的测试结构
- 输出更详细的测试结果对比信息
